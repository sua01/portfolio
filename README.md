# 윤수아 | Portfolio Website

AWS 인프라, 보안 모니터링, Text-to-SQL 프로젝트와 IT 인턴 경험을 소개하는 포트폴리오 웹사이트입니다.

## GitHub Pages로 배포하기

1. GitHub에서 새로운 **Public** repository를 만듭니다. 예: `portfolio`.
2. 이 폴더의 `index.html`, `portfolio.pdf`, `assets` 폴더를 저장소 **최상위 경로**에 업로드합니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. **Branch: main**, **Folder: / (root)**를 고르고 **Save**를 클릭합니다.
5. 배포 완료 후 `https://깃허브아이디.github.io/portfolio/` 주소로 접속합니다.

## 수정 방법

- 문구, 경력, 프로젝트: `index.html`에서 수정합니다.
- 색상: `index.html` 상단의 CSS `:root` 색상 변수를 바꿉니다.
- 프로젝트 이미지: `assets/` 파일을 교체합니다.
- 최신 PDF: `portfolio.pdf`를 새 파일로 교체합니다.
- 공개를 원하지 않는 개인 정보가 없는지 배포 전 확인하세요.

원본 자료: 제공된 `포트폴리오_윤수아.pdf`. 웹사이트 설명 일부는 웹에 맞게 요약/재구성했습니다.
